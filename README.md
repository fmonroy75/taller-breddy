# L’atelier BREDDY Inc.

Site Nuxt 3 bilingue (FR/EN) pour L’atelier BREDDY Inc., structuré autour de :

- Accueil
- Bois & Époxy
- Soudure & Métal
- Conception 3D
- Contact

## Images

Les images sont classées par usage dans `public/images/` :

- `brand/`
- `accueil/`
- `bois-epoxy/hero/`
- `bois-epoxy/galerie/`
- `soudure-metal/hero/`
- `soudure-metal/galerie/`
- `conception-3d/hero/`
- `conception-3d/galerie/`

Les fichiers `photo-a-ajouter*.svg` indiquent volontairement les emplacements où les vraies photos de soudure et de conception/impression 3D doivent être ajoutées. Ils ne représentent pas des réalisations réelles de l’atelier.

Les liens Instagram et Facebook sont laissés en attente de confirmation des URL exactes.

## Développement

```bash
npm install --include=optional
npm run dev
npm run build
npm run preview
```
